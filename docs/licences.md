# Image and audio licences and attribution

The machine-readable manifests are the source of truth: `content/images.json` for pictures (the content validator fails if a lesson uses a picture that is not listed there, or whose file is missing) and `content/audio/recordings.json` for recordings (created by the first `npm run audio:import`). This page summarises them.

## Pictures

All 81 pictures are original artwork made for this project, drawn in code by `scripts/illustrations/draw.ts` so the style stays consistent and every picture can be regenerated or adjusted. They are released under the repository licence (MIT, copyright 2026 KingsmanRon). People are adults with a range of skin tones in South African settings.

| Group | Count | Files |
|---|---|---|
| Profile pictures (avatars) | 12 | `public/images/avatar-*.svg` |
| Secret-code pictures | 9 | `public/images/pin-*.svg` |
| Badges | 12 | `public/images/badge-*.svg` |
| Lesson pictures: words, people, places, money and phone | 35 | for example `cat.svg`, `bus.svg`, `clinic.svg`, `airtime.svg`, `id-book.svg`, `sms.svg` |
| Signs and their meanings | 12 | `sign-*.svg` (Stop, Exit, Danger, Toilets, Open, Closed) and `meaning-*.svg` |
| App icon | 1 | `app-icon.svg`; the PNG icons in `public/icons/` are rendered from it by `scripts/illustrations/icons.ts` |

Each entry in `content/images.json` records the file, a text description (used as its accessible name), author ("Yomu project contributors"), licence ("MIT (repository licence)"), source ("Original artwork drawn in code") and creation date. Any picture added later from elsewhere must be listed with its real author, licence and source URL, and must be licensed for modification and redistribution in an app; pictures without a recorded licence cannot be used.

Signs are drawn as generic pictograms in the style of common South African signage, not copied from official sign artwork.

## Audio

| Audio | Licence | Status |
|---|---|---|
| Placeholder tones (`public/audio/placeholder/`, generated at build time by `npm run audio:placeholders`) | MIT (generated by the project's scripts with ffmpeg) | Every line today |
| Sound-check chime | Generated on the phone (Web Audio); no file | In use |
| Voice recordings in isiZulu, Sesotho and English | To be recorded under a release from each voice artist | None yet: 0 of 875 lines |

For every recording session, keep with the project's records (not in the repository): the voice artist's signed release (use, editing and distribution in the app and its promotion; perpetual; credit preference), the session date, and the director. Record in this file, per language: the artist's credit name as they wish it to appear, the session dates and the licence granted. No recording may be imported without a release.

## Fonts

No font files are shipped or downloaded. The app uses the phone's own system fonts (the stylesheet names Andika and Lexend first, which are used only if already installed on the device).

## Software

The app's own code is MIT-licensed (`LICENSE`). Runtime dependencies keep their own licences, all permissive: Next.js, React, Supabase JS, zod, pdf-lib and qrcode (MIT), idb (ISC), and the Anthropic SDK (Apache-2.0). `npm ls --all` lists the full tree; run a licence check (for example `npx license-checker --summary`) before a public release.
